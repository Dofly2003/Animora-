# Test place

Save the Studio test place here as `Animora-TestPlace.rbxl`. It should contain:

- An R6 rig (Avatar → Rig Builder → Block Rig R6)
- An R15 rig (Rig Builder → Block Rig R15)
- One custom Motor6D rig (e.g. a door, a sword or a creature) with non-standard part names

Every release is checked against all three rigs before publishing.
